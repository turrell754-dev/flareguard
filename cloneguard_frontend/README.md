#flareguard frontend prototype

## Load in Chrome
1. Unzip the project.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Choose **Load unpacked** and select this folder.
5. Pin CloneGuard to the toolbar and open the popup.

## Included
- Dark cybersecurity popup dashboard
- Protection toggle stored with `chrome.storage.local`
- Current-tab URL display and basic heuristic demo checks
- Recent check history
- Settings page
- Standalone warning page with a strict demo allowlist for redirect destinations
